An assistant that picks the right tool for every question

A router reads your question and sends it to the best source — the LLM itself, Wikipedia, the live web, arXiv, your own PDFs or your images — then streams a grounded answer with its sources.

Open chat

How routing works

Every question takes exactly one route. Attachments decide the route directly; otherwise an LLM router chooses.

DIRECT

General questions the language model can answer on its own.

WIKIPEDIA

Factual, historical and general-knowledge lookups.

TAVILY

Current events and anything that needs the live web.

ARXIV

Academic and research-paper questions.

PDF_RAG

Questions about a PDF you uploaded, answered only from that document with page citations.

IMAGE

OCR plus a vision model read and describe an image you uploaded.

PDF question answering

Ingestion

Text extraction with an OCR fallback for scanned pages, cleaning, structure-aware chunking and multilingual embeddings stored in Postgres + pgvector.

Retrieval

Query transformation, hybrid dense + keyword search, reranking, diversity selection and neighbour-aware context building before the answer is written.
